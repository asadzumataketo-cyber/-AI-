# 2026/10/31–11/1 中央競馬 AI 事前順位予測テスト

## 今週末の主目的（10/28 最新決議）
**発走前の全出走馬の予想着順と、確定した着順がどれだけ一致するか検証する。**

- **最優先:** 事前の順位予測を固定し、当日の全頭の確定順位と比較。利益・回収率・1000円の仮想予算は今回の主題から外す。将来の遊びとしての仮想評価は別プロジェクトで任意に検討する。
- 中央競馬JRAを優先。地方競馬NAR開発はPhase2に延期。
- JRA公式出馬表・過去走など、権利・利用規約上適法な情報のみ利用。未取得情報は「欠損」と表示し、推測で埋めない。
- 10万回のNumPy試行は予測順位・勝率推定の内部計算として維持する。試行回数が多いだけで着順予測の品質が高くなるわけではない。
- 発走前スナップショットは race_id / as_of / model_version / seed / all_horses / estimated_probabilities / predicted_rank / used_sources を保存してロックする。レース後に内容を書き換えない。
- 実際の馬券購入・払戻・送金は行わない。今週末は分析・検証のみ。
- **4レースはシステム動作検証のための最小サンプル。予測の統計的な優位性はまだ証明できない。**

## 事前予測の保存項目

| フィールド | 説明 |
|---|---|
| race_id / event_timestamp / as_of | 対象と予測時点 |
| horse_id / horse_name / number | 全出走馬の識別子 |
| predicted_rank | 予測上の順位（1位〜最下位） |
| p_win / p_2nd / p_3rd / p_top3 | 勝率、2着率、3着率、3着以内率 |
| model_version / random_seed / simulations | モデル版・乱数seed・試行数100000 |
| feature_snapshot / source_url / published_at | 入力特徴量・出典・公開時点と欠損情報 |

予測順位は **推定1着確率 p_win の降順** を基本とし、同点時は馬番号昇順で固定。全頭のランキングを必須とする。

## 順位一致の主要評価

1. **勝ち馬的中:** 予測1位の馬が実際に1着なら1、そうでなければ0。
2. **Top3重複数:** 予測上位3頭のうち、確定上位3頭に含まれる頭数（0～3）。
3. **1–3着完全一致:** 予測1位・2位・3位の馬と実際の1・2・3着が順番まで一致したら1。
4. **真の勝ち馬の予測順位:** 実際の勝ち馬が予測ランキングで何位だったか。
5. **全馬の順位一致:** Kendall tau-b か有効ペア一致率。取消・除外・競走中止・失格・同着の場合の対象頭数と処理ルールを固定してから計算し、欠損・除外数を報告する。

**補助:** 勝ち馬one-hotの多クラス Log Loss / Brier Score、同時点のオッズのみを使うベースライン比較、特徴量欠損率。
